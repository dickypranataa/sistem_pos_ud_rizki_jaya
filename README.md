## Sistem Manajemen Stok dan Point Of Sales dengan Assisten AI Google Gemini

Sistem Point of Sales (POS) berbasis web komprehensif yang dirancang untuk mengotomatisasi transaksi kasir dan manajemen inventaris. Aplikasi ini dibangun untuk menyelesaikan tantangan operasional dalam pencatatan multi-level harga dan pelacakan riwayat stok barang secara akurat, memastikan sinkronisasi data dari kasir hingga laporan analitik untuk manajemen.

Fitur :
- Kasir Real-Time dengan Livewire
- Sistem Multi-Harga (Grosir, Semi Grosir, Retail)
- Audit & Riwayat Stok Otomatis
- Laporan Pintar (Excel & PDF)
- Hak Akses Admin & Kasir
